المصري ستور - مشروع أندرويد

هذا مشروع Android Studio يحتوي على نسخة HTML الحالية من برنامج الكاشير داخل WebView.
هذا الملف ZIP هو مشروع مصدر قابل للبناء، وليس ملف APK جاهزاً للتثبيت.

طريقة إخراج APK:
1) نزّل Android Studio على كمبيوتر.
2) فك ضغط الملف وافتح مجلد AlmasriStoreAndroid في Android Studio.
3) انتظر اكتمال Gradle Sync وتثبيت Android SDK المطلوب.
4) من القائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).
5) عند اكتمال البناء اختر Locate، وستجد app-debug.apk داخل app/build/outputs/apk/debug/.

ملاحظات:
- بيانات البرنامج محفوظة محلياً في تخزين WebView؛ حذف بيانات التطبيق قد يؤدي لفقدانها، لذا استخدم النسخ الاحتياطي داخل البرنامج إن كان متاحاً.
- تم إعداد إذن الكاميرا، لكن مسح الباركود بالكاميرا يحتاج اختباراً على الجهاز وقد يتطلب تعديل طريقة فتح الكاميرا إذا كانت صفحة HTML تعتمد على واجهات المتصفح غير المدعومة في file://.
- هذا البناء يضم ملف index.html الحالي فقط؛ لا يعني ذلك أن جميع الميزات التي طُلبت سابقاً قد أضيفت أو اختُبرت.
